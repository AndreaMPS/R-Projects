 #                          ~ Maternal Mental Health Impact on Infant Sleep ~ 

**Primary Research Question: What factor(s) influence the frequency of nighttime awakenings in infants during their first year of life?**

**Secondary Research Question(s): What is the relationship between a mother’s marital status and her baby’s sleep pattern?
How does a baby's age influence their preference of being put to sleep by parents ?
What is the relationship between a mothers health and marital status with her baby’s sleep pattern by age ?**


**Introduction: Retrospective analysis exploring the factors that influence infant sleep patterns because of how essential sleep is to both child development and 
family functioning. Current research indicates a link between maternal well-being and infant sleep, suggesting that factors like
age, marital status, and postpartum depression can lead to poorer sleep outcomes for newborns**

**Getting Started - How to Run:** 
1. Note whether you would like to work in systematic parts or a total combined file [Maternalhealthcombined.rmd]
2. Download and unzip appropriate files in one location
3. Set working folder in R Studio as the location with the files 
4. Import dataset [Dataset_maternal_mental_health_infant_sleep.rmd] into R studio environment
5. Open [Maternalhealthvisualization.rmd] and run the chunks of code
6. Open [MaternalDescriptive.rmd] and run the chunks of code
7. Open [MaternalHypothesis.rmd] and run the chunks of code
8. Open [Maternalresults.rmd] and run the chunks of code

  *Original Study Source: Sandoz, V., Lacroix, A., Stuijfzand, S., Bickle Graz, M., & Horsch,
A. (2022). Maternal Mental Health Symptom Profiles and Infant Sleep: A Cross
Sectional Survey. Diagnostics, 12(7), 1625.
https://doi.org/10.3390/diagnostics12071625*

  *Data Source: Dataset of The distinct influence of different
