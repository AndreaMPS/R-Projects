 #                          ~ Maternal Mental Health Impact on Infant Sleep ~ 

**Research Question: What factor(s) influence the frequency of nighttime awakenings in infants during their first year of life?**

**Introduction: Exploring the factors that influence infant sleep patterns because of how essential sleep is to both child development and 
family functioning. Current research indicates a link between maternal well-being and infant sleep, suggesting that factors like
age, marital status, and postpartum depression can lead to poorer sleep outcomes for newborns**

**Getting Started - How to Run: 
    1. Note whether you would like to work in systematic parts or a combined file [Maternalhealthcombined]
    2. Download and unzip appropriate files 
    3. Import dataset [Dataset_maternal_mental_health_infant_sleep] into R studio environment
    4. Open [Maternalhealthvisualization] and run the chunks of code
    5. Open [MaternalDescriptive] and run the chunks of code
    6. Open [MaternalHypothesis] and run the chunks of code
    7. Open [Maternalresults] and run the chunks of code**
